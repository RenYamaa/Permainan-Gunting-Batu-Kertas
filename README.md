## Cara Cobain Gamenya Gimana Tuh??
Gampang banget kok, ikuti langkah-langkah ini (walau gw juga ga yakin ada yang mainin, tapi **siapa tau** kan ada yang mau??):
- Pastiin kamu udah instal Node.js ya!
- Buka terminal atau CMD-mu.
- Instal library yang dibutuhkan. Cukup sekali aja kok:
```
npm install prompts readline-sync
```
- Jalanin deh kodenya, caranya:
```
node nama_file_mu.js
```
(Ganti nama_file_mu.js dengan nama file JavaScript-mu!)
